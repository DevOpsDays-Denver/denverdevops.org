What is DevOpsDays?

DevOpsDays Rockies in Denver is back for its 10th year!

DevOpsDays is a worldwide series of community-focused technical conferences covering topics of software development, IT infrastructure operations, and the intersection between them. Each event is run by volunteers from the local community.
